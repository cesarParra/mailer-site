mailer privacy policy

mailer is a personal app used by one person, its developer, on their own computer.

What it accesses

With the user's consent, mailer reads and modifies the user's own Gmail and reads and writes the user's own Google Calendar.

Where data is kept

Email and calendar data are stored in a database on the user's computer. Sign-in credentials are stored in the macOS Keychain. mailer has no server, and nothing is sent to its developer.

What is sent elsewhere

To rank and summarize messages, parts of messages are sent to AI services the user has configured: TypeSafe's Jev model and an AI text service. Data is not sold, shared for advertising, or used for any other purpose.

Google user data

mailer's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the app's database removes all stored data.
